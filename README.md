# SKYWHY

> Fear doesn't chase you. It waits.

## 🎮 About

SKYWHY is a modern psychological horror game for Android.

The game is being developed using Godot 4 and GitHub Actions.

Current Version:
v0.0.1 Alpha

Platform:
Android

Target FPS:
60 FPS

Orientation:
Landscape

Engine:
Godot 4
